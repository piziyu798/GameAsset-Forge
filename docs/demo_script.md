## 一、开场介绍

大家好，我展示的项目是 GameAsset-Forge，一个面向学生团队和独立开发者的 2D 游戏素材生成工作台。

它不是单纯生成一张 AI 图片，而是围绕游戏 Demo 开发流程，完成从素材需求、素材蓝图、风格锁定、Prompt 生成、Demo/API 生成、素材展示、质量检查到工程化导出的完整流程。

---

## 二、项目痛点说明

在早期游戏 Demo 开发中，很多团队会遇到三个问题：

第一，不知道一个游戏原型需要准备哪些基础素材。

第二，即使用 AI 绘图，也容易出现风格不统一、命名混乱、素材难以管理的问题。

第三，普通图片生成工具缺少工程化导出能力，不能直接形成游戏项目可用的素材包。

所以本项目的目标是把“AI 绘图”组织成“AI 游戏素材工作流”。

## 三、演示步骤

### Step 1：项目配置

首先填写游戏名称、游戏类型、主题、美术风格、素材尺寸、游戏视角、背景要求和色彩主题。

这些参数会作为后续素材蓝图和 Prompt 生成的约束。

### Step 2：素材需求描述

接着填写希望生成的具体素材，例如：

    骑士主角、忍者角色、女巫角色、绿色史莱姆、金币、红色药水、草地地图块、森林背景

系统会把这些素材和默认素材蓝图合并。

### Step 3：选择生成模式

系统支持 Demo Mode 和 API Mode。

Demo Mode 使用内置素材池，可以稳定展示完整流程。

API Mode 可以配置图像生成 API，根据 Prompt 生成真实图片。

当前 API Mode 默认使用：

    API Base URL: https://api.siliconflow.cn/v1
    模型名称: Tongyi-MAI/Z-Image-Turbo

如果现场网络或额度不稳定，可以切回 Demo Mode 完成演示。

### Step 4：生成素材蓝图与风格档案

点击“生成素材蓝图与风格档案”。

可以看到系统生成了项目配置结果、Style Lock 风格档案和素材清单。

### Step 5：编辑素材清单

用户可以继续修改素材名称、类型、描述和是否生成。

这一步体现了它不是一次性黑盒生成，而是可编辑的素材工作台。

### Step 6：生成 Prompt

点击“生成 Game-aware Prompt”。

系统会根据素材类型生成不同 Prompt，例如角色、敌人、道具、地图块和 UI 的 Prompt 重点不同。

### Step 7：生成素材

如果选择 Demo Mode，点击“生成 Demo 素材”。

如果选择 API Mode，填写 API Key 后点击“生成 API 素材”。

生成结果会进入同一个素材库，并按角色、敌人、道具、地图块、UI 和背景分类展示。

### Step 8：质量检查

点击“进行质量检查”。

系统会检查素材字段、图片路径和 Prompt 记录，并显示通过情况。

### Step 9：导出素材包

点击“导出素材包 ZIP”。

系统生成结构化素材包，并提供下载按钮。

导出的素材包中包含：

- 分类图片；
- manifest.json；
- README.md。

## 四、Demo Mode 与 API Mode 说明

Demo Mode 和 API Mode 是本项目的双模式设计。

Demo Mode 用于保证没有 API Key 时也能稳定演示完整流程。

API Mode 用于调用真实图像生成服务，根据 Prompt Composer 输出结果生成真实素材。

两种模式的生成结果都会进入同一套素材库、质量检查和 ZIP 导出流程。

---

## 五、项目亮点总结

本项目的亮点主要有五个：

第一，从单张 AI 绘图升级为完整游戏素材工作流。

第二，通过 Asset Blueprint 帮助用户规划素材清单。

第三，通过 Style Lock 和 Prompt Composer 提高素材生成的一致性。

第四，通过 Demo Mode 保证项目稳定可演示。

第五，通过 API Mode 接入真实图像生成能力，并通过质量检查和 ZIP 导出让素材更接近工程可用状态。
