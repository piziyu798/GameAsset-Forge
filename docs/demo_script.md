# Demo 视频脚本

## 1. 开场介绍

大家好，这是 GameAsset Forge，一个面向学生团队和独立开发者的 2D 游戏素材生成工作台。

它不是简单的 AI 绘图页面，而是围绕 2D 游戏原型开发设计的完整素材生成流程。

## 2. 用户痛点

在制作 2D 游戏 Demo 时，学生团队和独立开发者经常遇到几个问题：

- 缺少美术资源；
- 不知道需要哪些基础素材；
- 网上素材风格不统一；
- AI 绘图工具只生成单张图片；
- 素材难以直接进入游戏工程。

## 3. 创建项目

首先，用户输入游戏名称、游戏类型、主题、风格、尺寸和视角。

例如：

- 游戏类型：RPG
- 主题：森林冒险
- 风格：像素风
- 尺寸：64x64
- 视角：俯视角

## 4. 生成素材蓝图

系统会根据游戏类型生成推荐素材清单，例如：

- 小骑士主角；
- 魔法师；
- 弓箭手；
- 史莱姆；
- 哥布林；
- 蝙蝠；
- 金币；
- 药水；
- 草地地图块；
- 血条。

用户可以继续修改、删除或新增素材。

## 5. 风格锁定

通过 Style Lock，系统会统一控制风格、尺寸、视角、背景和颜色，使同一项目内的素材更一致。

## 6. Prompt Composer

系统会根据不同素材类型生成不同的专业 Prompt。

例如地图块会强调 tileable 和 seamless，角色会强调 sprite、full body 和 transparent background。

## 7. 生成素材

系统支持 Demo Mode 和 API Mode：

- Demo Mode 使用内置示例素材，保证项目开箱即用；
- API Mode 可以调用真实图像生成模型。

## 8. 素材库展示

生成后的素材会进入素材库，并按照角色、敌人、道具、地图块、UI、背景分类展示。

## 9. 质量检查

系统会检查素材命名、分类、Prompt 记录和导出结构，判断素材包是否具备基本工程可用性。

## 10. 导出素材包

最后，用户可以导出一个结构化素材包，包含分类目录、manifest.json 和 README.md，便于进入游戏开发流程。

## 11. 总结

GameAsset Forge 的核心价值是：从单张 AI 绘图升级为面向游戏开发流程的 AI 素材工作流。
