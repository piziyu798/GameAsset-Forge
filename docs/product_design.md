# 产品设计文档

## 1. 产品名称

GameAsset Forge｜2D 游戏素材生成工作台

## 2. 产品定位

GameAsset Forge 是一个面向学生团队、独立开发者和 Game Jam 参赛者的 2D 游戏素材生成工作台。

本产品不是单纯的文生图工具，而是围绕 2D 游戏原型开发流程，提供从需求输入、素材蓝图生成、风格锁定、Prompt 编排、素材生成、素材管理、质量检查到工程化导出的完整流程。

## 3. 核心理念

从“AI 绘图”升级为“AI 游戏素材工作流”。

## 4. 目标用户

- 学生游戏开发团队
- 独立游戏开发者
- Game Jam 参赛者
- 需要快速制作游戏 Demo 的产品、策划或开发人员

## 5. 用户痛点

1. 缺少美术资源，无法快速完成游戏 Demo；
2. 网上素材来源分散，风格不统一；
3. 用户不清楚一个 2D 游戏原型需要哪些基础素材；
4. 普通 AI 绘图工具只生成单张图片，缺少素材包概念；
5. 生成结果缺少命名、分类、质量检查和导出流程。

## 6. 第一版功能范围

- 项目配置
- 素材蓝图生成
- 素材清单编辑
- 风格锁定
- Game-aware Prompt Composer
- Demo/API 双模式
- 素材库分类展示
- 质量检查
- 素材包导出

## 7. 第一版暂不实现

- 用户登录系统
- 多人协作
- 大规模素材 RAG 数据库
- 动画帧生成
- 地图编辑器
- 完整游戏引擎集成

## 8. 产品创新点

1. 不是生成单张图片，而是生成游戏素材工作流；
2. 使用 Asset Blueprint 帮助用户理解游戏素材组成；
3. 使用 Style Lock 提升同一项目内素材风格一致性；
4. 使用 Game-aware Prompt Composer 让 Prompt 更符合游戏素材规范；
5. 使用工程化导出，让素材更容易进入 Unity、Godot 等开发流程。
