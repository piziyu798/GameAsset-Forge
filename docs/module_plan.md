# GameAsset-Forge 模块开发计划

## 一、开发原则

本项目按照模块拆分 Pull Request，避免最后一次性提交全部代码。

每个 PR 尽量围绕一个独立功能展开，保证开发记录清晰、可追踪、可解释。

---

## 二、PR 拆分计划

### PR1：初始化项目结构与基础文档

目标：

- 创建项目目录；
- 添加 README；
- 添加 Streamlit 入口；
- 添加 docs 文档骨架；
- 添加 requirements.txt。

### PR2：项目配置、素材蓝图与风格锁定

目标：

- 实现项目配置表单；
- 新增游戏类型素材蓝图；
- 新增 Style Lock 风格模板；
- 根据配置生成基础素材清单和风格档案。

### PR3：素材清单编辑与 Prompt Composer

目标：

- 支持素材清单编辑；
- 支持新增、修改、删除素材；
- 新增 Prompt 模板；
- 根据素材类型生成 Game-aware Prompt。

### PR4：Demo 素材生成与素材库展示

目标：

- 使用 Pillow 生成 36 张内置 Demo 素材；
- 新增 Demo 素材 manifest；
- 支持根据素材清单匹配 Demo 图片；
- 在页面中按分类展示素材卡片；
- 说明 Demo Mode 和 API Mode 的边界。

### PR5：质量检查与素材包导出

目标：

- 新增素材质量检查；
- 新增素材包导出；
- 导出 manifest.json；
- 导出 README.md；
- 打包 asset_pack.zip；
- 增加下载按钮；
- 补充素材需求描述输入。

### PR6：API Mode 图像生成接入

目标：

- 新增 API 图像生成模块；
- 支持 API Key、API Base URL、模型名称和输出尺寸配置；
- 默认接入硅基流动 API；
- 默认模型使用 Tongyi-MAI/Z-Image-Turbo；
- 兼容硅基流动参数和 OpenAI 风格参数；
- 将 API 生成结果接入素材库、质量检查和导出流程；
- 更新 .gitignore，避免提交运行产物。

### PR7：完善最终项目文档与 Demo 演示说明

目标：

- 完善 README；
- 完善产品设计文档；
- 完善架构设计文档；
- 完善模块开发计划；
- 完善 Demo 演示脚本；
- 文档中明确当前已支持 Demo/API 双模式；
- 为最终展示提供完整说明。
